Conseils pour ce niveau

  1. 1

    Plan three moves ahead before sliding the first block.

  2. 2

    Treat blocking pieces as 'parking' — slide them out of the way temporarily.

  3. 3

    L-shaped and T-shaped blocks usually rotate the puzzle's logic — solve around them first.

  4. 4

    When two colors race for the same lane, pick the one whose path is fully open.

  5. 5

    Use the preview to confirm a block actually fits its target gate before committing.
